# ComfyUI Easy-Use Image Chooser · Node 2.0

为 [ComfyUI-Easy-Use](https://github.com/yolain/ComfyUI-Easy-Use) 的 `easy imageChooser` 提供独立的 Node 2.0 选图界面。

运行到选择节点时，工作流暂停，弹出可拖动、可收起的浮窗。可以查看候选图片、对比两张结果、选择一张或多张图片，然后继续工作流。继续使用原有 `easy imageChooser`，已有工作流无需替换节点或修改接线。

## 功能

- Node 2.0 下暂停选图，支持连续多个选择点。
- 多选、取消选择、继续工作流、停止本次运行。
- 非模态浮窗：可以拖动标题移动位置，拖动右下角调整窗口大小，也可以收起后操作画布。
- 两张及以上候选图片可滑动对比，支持选择 A/B 图片和扩大对比区域。
- 选图和对比区域支持鼠标滚轮缩放（25%–800%）、中键拖动和双击恢复适应；对比的两张图片同步缩放与移动。
- 收起、展开和对比操作保留已选图片，不会自动继续执行。
- 提交失败时保留窗口，支持重试。
- 普通画布模式沿用 Easy-Use 原有交互；`Keep Last Selection` 沿用原有选择逻辑。

## 安装

先安装 ComfyUI 和 [ComfyUI-Easy-Use](https://github.com/yolain/ComfyUI-Easy-Use)。本扩展无需额外 Python 依赖。

下载本仓库后，将文件夹命名为 `ComfyUI-Easy-Use-Chooser-Nodes2`，放入：

```text
ComfyUI/
└── custom_nodes/
    └── ComfyUI-Easy-Use-Chooser-Nodes2/
        ├── __init__.py
        └── web/
            └── image_chooser_nodes2.js
```

重启 ComfyUI，在网页按 `Ctrl+F5` 刷新，再开启 Node 2.0。

如果曾将同名 `image_chooser_nodes2.js` 补丁放入 Easy-Use 的 `web_version/v2`，请先移出旧补丁，避免重复加载。更新已安装的本扩展时，替换文件后按 `Ctrl+F5` 刷新。

## 使用

1. 在原 `easy imageChooser` 节点中，将 `mode` 设为 `Always Pause`。
2. 运行工作流。执行到选择节点时，浮窗显示该节点标题和候选图片。
3. 点击图片选择结果，可以多选；选中图片会显示绿色边框。
4. 点击“继续工作流”，把已选图片传给下游节点。

适用于“生成 → 选择 → 放大 → 再次选择 → 保存”等已有工作流。实际分支和保存位置由工作流接线决定。

**比较图片：** 候选图片至少两张时，点击“对比图片”，分别选择左侧 A、右侧 B 的图片，拖动分界线查看差异。“放大查看”扩大对比区域；“返回选图”回到候选列表。对比操作不改变输出选择。

**缩放细节：** 鼠标移到候选图片或对比区域，滚轮向上放大、向下缩小，以鼠标所在位置为中心。按住鼠标中键拖动查看其他位置，双击图片恢复适应。对比区域内左键仍用于拖动分界线。缩放只影响预览，不改变输出图片。

**调整窗口大小：** 拖动浮窗右下角的对角线把手可放大或缩小整个浮窗，窗口变大后图片列表和对比区域会占用更多空间；把手上双击恢复默认尺寸，也可用方向键微调（`Shift` 加速）。收起浮窗或切换“放大查看”后恢复默认尺寸。

**查看画布：** 点击“收起看画布”，可继续操作画布；点“展开选图”返回。焦点在浮窗内时，`Esc` 只收起浮窗。停止任务请点击“停止本次运行”。

## 兼容范围与限制

- 本扩展复用 Easy-Use 的暂停与选图接口，只提供前端兼容界面，不新增后端节点。
- 浮窗对比使用当前选择节点收到的候选图片，不依赖其他 Compare 节点是否已经执行。
- 收起浮窗不会为画布上的对比节点生成图片，也不会改变节点执行顺序。
- 第三方 `Image Comparer (rgthree)` 在 Node 2.0 下可能出现空白或无法交互；本扩展不修复该节点。可以使用浮窗内置对比，或使用适用于当前 ComfyUI 版本的自带对比节点。
- 已验证根工作流中的原有选择节点；尚未独立验证任意深度嵌套子图中的选择节点，不保证该场景兼容。
- Node 2.0 和 Easy-Use 的前端接口可能随版本改变。报告问题时请附上 ComfyUI、前端和 Easy-Use 版本。

## 卸载

将本扩展文件夹移出 ComfyUI 的 `custom_nodes` 目录，重启 ComfyUI 并刷新网页。原 Easy-Use 节点和已有工作流可以继续保留。
